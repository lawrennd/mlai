# CIP-0008: Teachable Hamiltonian Monte Carlo Component (Neal)

## Status
- [x] Proposed
- [x] Accepted
- [x] In Progress
- [ ] Implemented
- [ ] Closed

## Summary
Add a small, readable Hamiltonian Monte Carlo (HMC) module to `mlai`, faithful to Radford Neal's hybrid Monte Carlo formulation, for use in teaching notebooks and lectures (including IEI Week 1's loss-as-potential → kinetic → Hamiltonian arc). This is the first concrete HOW for [REQ-0008](../requirements/req0008_teachable-sampling.md).

## Motivation
Lectures already treat training losses as *energies* and show gradient descent as walking downhill on a potential. The natural next question — *where is the kinetic energy?* — leads to the Hamiltonian $H=K+V$ and to HMC. The `mlai` package has contour and gradient-descent plotting helpers (`plot.regression_contour`, `plot.regression_contour_fit`, SGD variants) but no first-class HMC sampler. Existing research libraries (Stan, NumPyro, BlackJAX) are excellent for production sampling and poor as a first teaching contact: too much machinery between leapfrog and the student.

We need a *teachable* component: short enough to read in one sitting, close to Neal's [@Neal:hmc92] hybrid Monte Carlo for neural nets, and wired so a lecture can replace an SGD fit of a small network with an HMC posterior demo without leaving the `mlai` ecosystem.

## Detailed Description

### Current State (2026-09-29)
- **Core sampler shipped**: `mlai/hmc.py` with `HamiltonianMonteCarlo`, `leapfrog`, `kinetic_energy`, `HMCResult`
- Exported from `mlai`; 16 unit tests in `tests/unit/test_hmc.py` (Gaussian moments, conservation, seeds, accept rate)
- Lecture include `_ml/includes/from-loss-to-hamiltonian.md` still needs live import wiring (teaching backlog)
- Contour / trajectory plot helpers not yet added (plot backlog)
- Complements CIP-0007 (point-estimate optimisers); sampling stays a separate surface under REQ-0008

### Scope
1. **Core sampler** (`mlai/hmc.py` or similar under the modular layout from CIP-0006):
   - Kinetic energy $K(\mathbf{p})=\frac{1}{2}\mathbf{p}^\top M^{-1}\mathbf{p}$ (diagonal mass default)
   - Leapfrog integrator with configurable step size and number of steps
   - Metropolis accept/reject on $\Delta H$
   - API: `potential(q) -> float`, `grad_potential(q) -> array` (or autograd hook later)
   - Returns chain of `q` samples, accept rate, optional `H` trace

2. **Teaching demos** (notebooks or scripted examples under `mlai` docs / course notebooks):
   - 2D quadratic potential: overlay HMC proposals on the same contour style as `regression_contour`
   - Logistic or small MLP classification: SGD point estimate vs HMC posterior predictive
   - Explicit commentary linking $V=-\log p(q\mid\mathcal{D})$ to the lecture's energy language

3. **Plot helpers** (extend `mlai.plot`):
   - Trajectory segments of leapfrog paths on a 2D contour
   - Trace plots for $H$ and parameters

### Non-goals (this CIP)
- NUTS / adaptive HMC
- Riemannian / Hessian-informed mass matrices
- Full Stan parity
- Production-scale Bayesian deep learning

### Design constraints
- Prefer clarity over speed; NumPy-first, optional autograd later
- Docstrings should cite Neal [@Neal:hmc92] and point to [@Neal:bayesian94] for the neural-net setting
- Keep the public surface small enough that a lecture placeholder can become a real import without rewriting slides

## Implementation Plan

2. Implement `HamiltonianMonteCarlo` (name TBD) with diagonal mass
3. Add 2D contour trajectory plot helper
4. Add one neural / logistic teaching example using existing `mlai` network classes where possible
5. Wire IEI / MLFC notebook placeholders to the real import
6. Document with a short "HMC in one page" module docstring

## Backward Compatibility
Additive only. No change to existing SGD / contour APIs beyond optional new plot functions.

## Testing Strategy
- Analytic target $\mathcal{N}(0,I)$: empirical mean/covariance within tolerance
- Conservation: $|\Delta H|$ small for tiny step size; accept rate in a sane band for tuned steps
- Deterministic seed reproducibility for teaching notebooks
