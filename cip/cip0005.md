# CIP-0005: Simple Attention Implementation for Educational Purposes

## Status
- [x] Proposed
- [x] Accepted
- [x] In Progress
- [x] Implemented
- [ ] Closed

## Summary
Add a simple attention mechanism to the mlai library to support educational material on chain-rule computation in transformers. Focus on clear, pedagogical implementation that demonstrates the mathematical principles rather than production-ready transformer architecture. This is the first concrete HOW for [REQ-0005](../requirements/req0005_teachable-gradient-composition.md) (teachable multi-path gradient composition).

## Motivation
The transformer educational snippets (`chain-rule-transformer-attention.md` and `simple-transformer-implementation.md`) need a simple attention implementation to demonstrate chain-rule principles. Students need to understand mathematical flow of gradients through attention — especially the three-path case where the same input feeds Query, Key, and Value — not a production transformer stack.

## Detailed Description

### Delivered behaviour
Teachable attention lives in `mlai.neural_networks` (not a separate `transformer` package; composition with other layers mattered more than a dedicated module):

1. **`AttentionLayer`** — scaled dot-product attention with explicit forward/backward, self/cross/mixed modes, and three-path chain rule on self-attention inputs
2. **`MultiHeadAttentionLayer`** — composes multiple `AttentionLayer` heads and concatenates outputs
3. **`PositionalEncodingLayer`** — sinusoidal positional encoding as a `Layer`

### Current State (2026-09-29)
- Classes exported from `mlai` and used by snippets via `\loadcode{...}{mlai}`
- Gradient tests include numerical checks and `test_attention_layer_three_path_chain_rule`
- Teaching snippets in `snippets` already reference the library components
- Residual for closure: optional docs compression / CIP Closed once REQ-0005 acceptance criteria are reviewed more broadly
- Broader REQ-0005 (multi-path gradients *across* architecture families) remains open beyond this transformer instance

## Implementation Plan (completed)
1. Basic `AttentionLayer` with clear Q/K/V forward and explicit backward
2. `MultiHeadAttentionLayer` as wrapper around multiple `AttentionLayer` instances
3. `PositionalEncodingLayer` with sinusoidal formulation
4. Educational / numerical gradient tests, including three-path chain rule
5. Snippet integration (`simple-transformer-implementation.md`, `chain-rule-transformer-attention.md`)

## Backward Compatibility
Additive only: new layer classes in `neural_networks`. No breaking changes to existing APIs.

## Testing Strategy
- Unit tests focusing on gradient computation correctness (`tests/unit/test_neural_networks.py`)
- Numerical gradient verification for attention, multi-head, and positional encoding
- Mathematical validation of the three-path chain rule on self-attention
- Snippet-level usage as the educational integration check
