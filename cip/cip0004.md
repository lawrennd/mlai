## Summary
Replace the legacy MATLAB GP data-fit quadratic animation with a Python `plot.py` helper that emits SVG frames for the teaching docs. This is the first concrete HOW for [REQ-0004](../requirements/req0004_open-teaching-visuals.md) (open teaching visualizations).

## Motivation
The original sequence depended on MATLAB and LaTeX-oriented generation, which blocked educators without that toolchain and burdened maintenance. Moving it into `mlai.plot` keeps regeneration on the same open stack as the rest of the course figures.

## Detailed Description

### Delivered behaviour
`mlai.plot.gp_optimize_quadratic` renders the pedagogical sequence:
1. Elliptical contours for the quadratic data-fit term
2. Eigenvalue / principal-axis markup
3. Data-point and rotation frames for the animation

Outputs use the `gp-optimise-quadratic{NNN}.svg` naming expected by the docs pipeline. The snippets include `gp-optimize-data-fit.md` calls the Python helper via `\plotcode`.
